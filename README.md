# BankManagementSystem
A Java OOP project built as part of OOP course at University

Used Eclipse (Java 21, AWT GUI)

## OOP Concepts Used
1. Inheritance (SavingsAccount, CurrentAccount extend Account)
2. Polymorphism (calculateInterest() overridden differently)
3. Encapsulation (private fields with getters)
4. Abstraction (abstract class Account)
5. Interface (Transactable)
6. Exception Handling (InsufficientFundsException)
7. Collections (ArrayList)
8. Static Members

## Features
- Create Savings or Current Account
- Deposit & Withdraw Money
- View Account Details
- Custom exception for insufficient funds
- Simple AWT GUI

## How to Run
1. Install Java 21
2. Import project into Eclipse
3. Run Main.java
